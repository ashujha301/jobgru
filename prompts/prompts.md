# Jobgru prompts

```text
Jobgru prompts
```

Shows copy-edit-paste example prompts for a job search run.

Terminal:

```bash
jobgru prompts
jobgru prompts --which example_linkedin_swe_bangalore
jobgru prompts --json
```

GitHub: [prompts/jobgru-run.md](https://github.com/ashujha301/jobgru/blob/main/prompts/jobgru-run.md)

Filter catalog: `jobgru filter` or **Jobgru filter** in chat.
